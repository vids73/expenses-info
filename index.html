Expenses

Expenses is a private household expense tracker. It runs on its owner's own home server and is used only by the owner and the owner's family. It is not offered to the public.

What it does with Google

  • It copies the owner's own expense data into Google Sheets workbooks that the owner created and shared with the app.
  • It saves encrypted backup copies of that data in one folder, "Expenses backups", in the owner's own Google Drive. It uses the Google Drive permission "drive.file", so it can only see and change files and folders that it created itself.
