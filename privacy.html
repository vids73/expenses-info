Privacy policy: Expenses

Last updated: 7 November 2026. Back to the home page.

Expenses is a private household app that runs on its owner's own server. It has no other users and no developer-run service. No data is sent to the developer or to any third party.

Google user data the app accesses

  • Google Drive (drive.file): the app creates a folder named "Expenses backups" and uploads encrypted backup files into it. It can see and change only the files and folders it created. It cannot see any other file in the Drive.
  • Google Sheets: the app writes to spreadsheets that the owner created and explicitly shared with the app's service account.

How the data is used and stored

  • The data copied to Google is the owner's own expense records. It is used only to give the owner a copy in Sheets and a backup in Drive.
  • Backup files are encrypted before they leave the owner's server. The sign-in token is stored only on the owner's server.
  • The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
  • Data is not sold, shared, used for advertising or read by people.

Deleting data and removing access

The owner can disconnect Google Drive inside the app, remove the app at myaccount.google.com/permissions, and delete the "Expenses backups" folder and the spreadsheets at any time.
